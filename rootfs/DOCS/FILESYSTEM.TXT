XAVIEROS FILESYSTEM NOTES

The embedded root filesystem is XVRFS v1. It is read-only and embedded in the kernel.
The writable test filesystem is XVDISKFS v1 and is mounted at /DISK when a supported
QEMU ATA primary-master disk is available.

Useful commands:
  LS /DISK
  MKDIR /DISK/HOME
  WRITE /DISK/HOME/HELLO.TXT Hello from XavierOS
  CAT /DISK/HOME/HELLO.TXT
  STAT /DISK/HOME/HELLO.TXT

The disk filesystem is experimental and is not crash-safe. Attach only the disposable
disk image created by run.py. FORMAT DISK erases all files on that image.
