## О проекте

XavierOS — небольшое ядро на Rust без стандартной библиотеки, созданное для изучения низкоуровневого программирования. Оно загружается через Limine, рисует напрямую во framebuffer, обрабатывает ввод PS/2, управляет физическими страницами и heap, а также содержит экспериментальные подсистемы хранения данных и сети. В `0.2.0-beta.3` уменьшен прозрачный курсор до 28×28 пикселей и переработано приложение Settings: режимы разрешения выбираются карточками. При запуске через `run.py` со стандартным VGA QEMU Settings пытается применить разрешение сразу через Bochs VBE.

## Что уже есть

- **Bare-metal ядро Rust** для `x86_64-unknown-none` и загрузка через Limine.
- **Графический интерфейс framebuffer:** собственный bitmap-шрифт, полноэкранные фотообои с сохранением пропорций, верхняя панель и обновлённый Dock с векторными иконками и прозрачный PNG-курсор 64×64 как исходник, отображаемый в размере 28×28 с альфа-смешиванием и контрастным контуром.
- **Мышь и клавиатура:** PS/2-мышь в режиме polling, если устройство доступно; клавиатурная навигация по Dock как запасной вариант; выбор иконок, Escape для закрытия превью-окон и Terminal с настоящей консолью.
- **Приложения-превью:** Files показывает элементы VFS, Network — состояние E1000/IPv4, Clock — системное время, Settings позволяет интерактивно менять разрешение дисплея, About показывает информацию о сборке. Это простые панели внутри ядра, не отдельные пользовательские процессы.
- **Интерактивная оболочка:** история команд Up/Down, редактирование строки, Tab completion, учётные записи, файловые команды, диагностика и neofetch-подобный `SYSINFO`. Пока Terminal открыт, ядро продолжает вычитывать поток PS/2-мыши, чтобы её пакеты не блокировали клавиатуру. Введи `DESKTOP` в Terminal, чтобы вернуться к рабочему столу.
- **Память и прерывания:** Limine memory map, PMM, HHDM, heap, обработчики исключений IDT и таймер/клавиатура PIC/PIT.
- **Хранение:** ATA PIO, встроенный read-only XVRFS, VFS и записываемая XVDISKFS на постоянном диске QEMU.
- **Экспериментальная сеть:** E1000 в QEMU, DHCP с fallback, ARP/IPv4, ICMP `PING`, DNS/NTP и ограниченный HTTP-клиент.
- **Переносимые Python-скрипты сборки** для Windows, Linux и macOS; основная тестовая среда — QEMU.

## Сборка и запуск

### Требования

- Rust через `rustup` и Python 3.10+.
- QEMU с `qemu-system-x86_64` в `PATH`.
- На Windows сборочный скрипт может подготовить поддерживаемые вспомогательные инструменты. На macOS/Linux установи C-компилятор и `xorriso`.

```powershell
python setup.py
python -m unittest discover -s tests -v
python build.py --clean
python run.py
```

ISO появится в `build/xavieros.iso`. `run.py` подключает постоянный виртуальный диск на 16 МиБ: `data/xavieros-disk.img`. **Не используй `--reset-disk`, если хочешь сохранить файлы, аккаунты и настройки.**

## Управление рабочим столом

- **Мышь:** перемещай курсор и нажимай иконки Dock, если PS/2 auxiliary-устройство доступно.
- **Клавиатура:** стрелки влево/вправо выбирают иконку, Enter открывает её, Escape закрывает превью, `T` открывает Terminal. `F`, `N`, `C`, `S` и `A` открывают Files, Network, Clock, Settings и About.
- **Terminal:** введи `DESKTOP`, чтобы вернуться на рабочий стол. Все существующие команды оболочки остаются доступны.

Рабочий стол пока экспериментальный: Terminal — настоящая оболочка, остальные приложения — простые framebuffer-панели над существующими подсистемами ядра. Клавиатурные сокращения: `T`, `F`, `N`, `C`, `S`, `A` открывают Terminal, Files, Network, Clock, Settings и About. При проверке Terminal попробуй печатать, одновременно двигая мышь: ввод клавиатуры должен продолжать работать.

### Разрешение экрана и обои

В Limine добавлено стартовое меню с режимами `1024x768`, `1280x720` и `1366x768`. Во время загрузки выбери режим стрелками и нажми Enter; первый режим запускается автоматически через 5 секунд. Settings содержит выбираемые карточки 1024×768, 1280×720 и 1366×768. На стандартном VGA QEMU, который задаётся в `run.py`, кнопка Apply Mode запрашивает смену режима без перезагрузки через Bochs VBE. Если адаптер не поддерживает эту операцию, Settings покажет сообщение, а запасным вариантом остаётся меню Limine при загрузке. Фотообои масштабируются на весь экран с сохранением пропорций и центральным кадрированием.


## Команды консоли

Команды вводятся ASCII-текстом. Полный список смотри через `HELP`. Основные команды:

| Команда | Назначение |
|---|---|
| `SYSINFO` | Сводка XavierOS в стиле neofetch |
| `NET`, `NETSTAT`, `NETCHECK`, `PING` | Состояние сети и диагностика |
| `HTTPGET`, `FETCH` | Экспериментальный HTTP-клиент и скачивание файлов |
| `DATE`, `TIME`, `DATETIME`, `TIMEZONE`, `NTP` | Часы и NTP |
| `CONFIG`, `SETTINGS`, `REPORT` | Настройки и диагностический отчёт |
| `LS`, `CAT`, `STAT`, `WRITE`, `MKDIR`, `RM`, `DF`, `FSCK` | Файловые операции и проверки |
| `USERADD`, `LOGIN`, `LOGOUT`, `WHOAMI`, `PASSWD` | Экспериментальные пользовательские аккаунты |
| `HEALTH`, `SELFTEST`, `TASKS`, `HEAP`, `MEM` | Диагностика ядра и подсистем |
| `DESKTOP` | Вернуться из Terminal на рабочий стол |

## Настройки и файловая система

- `CONFIG SET TIMEZONE` задаёт фиксированное смещение относительно UTC (например, `TIMEZONE +0300`); автоматическое определение местоположения и перехода на летнее время не реализованы.
- `CONFIG SET NETWORK` выбирает DHCP или статический профиль QEMU. `CONFIG SAVE` сохраняет настройки на виртуальном диске.
- `REPORT SAVE` сохраняет диагностический отчёт в доступный путь под `/DISK`.
- `FSCK` — проверка метаданных только для чтения: она обнаруживает ошибки, но не ремонтирует диск. Перед экспериментами с файловой системой делай резервную копию виртуального диска.
- Часы используют CMOS RTC до успешной NTP-синхронизации. UDP NTP client является экспериментальным.
- Автоматическая проверка GitHub Releases пока не реализована. Для безопасного обращения к GitHub API нужна поддержка HTTPS/TLS.

## Статус и ограничения

XavierOS — **экспериментальная хобби-ОС**, а не система общего назначения или безопасная ОС. Desktop Preview работает внутри ядра; окна приложений не являются изолированными процессами. Учётные записи ограничивают команды оболочки, но не создают границу безопасности Ring 3. XVDISKFS не использует журнал и не гарантирует восстановление после аварийного выключения. Сеть ориентирована на эмулируемый E1000 и user-mode NAT QEMU; HTTPS/TLS, IPv6 и полноценные сетевые приложения не реализованы. Мышь PS/2 опрашивается программно, клавиатура остаётся запасным способом управления. Физическое оборудование не проверялось.

**Запускай XavierOS в QEMU или другой одноразовой виртуальной машине. Не полагайся на неё для защиты важных данных.**
