# XavierOS

**Версия 0.1.2** · Экспериментальная хобби-ОС для x86_64, написанная на Rust.  
[English README](README.md)

XavierOS — небольшое ядро `no_std`, загружаемое через Limine. Проект предназначен для обучения и экспериментов в QEMU, а не для повседневного или производственного использования.

## Возможности

- Загрузка через Limine, консоль на framebuffer, клавиатура PS/2, прерывания PIC/PIT и диагностика исключений через IDT.
- Аллокатор физических страниц, HHDM и heap ядра.
- Доступ к диску через ATA PIO и записываемая XVDISKFS на постоянном виртуальном диске QEMU.
- Read-only initramfs XVRFS и небольшой VFS-диспетчер монтирования.
- Прототип кооперативных задач и переключения контекста.
- Локальная база пользователей, вход по паролю, домашние каталоги и базовые ограничения доступа к путям на уровне shell.
- История из 16 команд: стрелки вверх/вниз и Tab-дополнение команд и доступных путей VFS.
- Переносимые Python-скрипты сборки и запуска для Windows, macOS и Linux.

## Сборка и запуск

Требуются Rust через `rustup`, Python 3.10+, QEMU и вспомогательные инструменты. В macOS/Linux установи C-компилятор и `xorriso`; в Windows скрипт подготовки может установить поддерживаемые вспомогательные инструменты.

```text
python setup.py
python -m unittest discover -s tests -v
python build.py --clean
python run.py
```

Сборка создаёт `build/xavieros.iso`. `run.py` подключает постоянный виртуальный диск размером 16 МиБ: `data/xavieros-disk.img`. Чтобы удалить и создать его заново (это удалит файлы и учётные записи), запусти `python run.py --reset-disk`.

## Учётные записи

XavierOS запускается во временной сессии `live`. На чистом диске создай первого пользователя — он станет администратором:

```text
USERADD alice
LOGIN alice
WHOAMI
HOME
PASSWD
```

Команда `USERADD` дважды запрашивает пароль и скрывает вводимые символы. Пароль должен содержать 8–63 печатных ASCII-символа; регистр учитывается. Вместо открытого текста сохраняется соль и хэш PBKDF2-HMAC-SHA256. Поддерживается до восьми постоянных учётных записей. Администратор может создавать дополнительных пользователей командой `USERADD bob`; обычный пользователь может обращаться к записываемому диску только через собственный каталог `/DISK/HOME/<имя>`. `LOGOUT` возвращает во временную сессию `live`, которая становится ограниченной после создания первого аккаунта. Команда `USERS` показывает список аккаунтов администратору.

## Командная оболочка

Нажимай **↑/↓**, чтобы просматривать историю команд. Нажми **Tab**, чтобы дополнить команду (например, `ho` → `HOME`) или однозначно совпадающий доступный путь к файлу/каталогу. При нескольких совпадениях ввод может дополниться до общего префикса; если префикс не меняется, строка остаётся без изменений.

Полезные команды: `HELP`, `SYSINFO`, `LS`, `CAT`, `WRITE`, `MKDIR`, `RM`, `DISK`, `TASKS`, `SELFTEST`, `WHOAMI`, `LOGIN`, `LOGOUT`, `PASSWD`.

## Ограничения и безопасность

- Менеджер пользователей экспериментальный. Команды работают в ring 0; это **не изоляция процессов в user mode и не защищённая граница безопасности**. Не используй настоящие пароли или пароли, которые применяются где-либо ещё.
- При наличии CPU RDRAND для соли используется он. На процессорах без RDRAND используется запасной вариант на основе таймера/TSC — он не является криптографически стойким генератором случайных чисел.
- XVDISKFS — небольшая файловая система без журнала и защиты от сбоев. Используй тестовые образы виртуального диска.
- Планировщик кооперативный. Пользовательские программы, изоляция виртуальных адресных пространств, сеть, рабочий стол и широкая поддержка физического оборудования пока не реализованы.
- Основная цель разработки и тестирования — QEMU; работа на физическом оборудовании не подтверждена.

`FORMAT DISK` стирает записываемую файловую систему, включая учётные записи. Образ постоянного диска хранится локально и исключён из Git.
