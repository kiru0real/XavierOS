## О проекте

XavierOS — небольшая хобби-ОС для изучения разработки ядра. Ядро написано на Rust без стандартной библиотеки (`#![no_std]`) для архитектуры `x86_64`. Загрузка выполняется через Limine. Проект предназначен для экспериментов в виртуальной машине, а не для повседневного или промышленного использования.

## Возможности

- Загрузка через Limine, framebuffer-консоль, клавиатура PS/2, обработчики исключений IDT, прерывания PIC/PIT и serial-диагностика.
- Карта памяти Limine, физический аллокатор страниц PMM, HHDM, heap ядра и прототип кооперативного переключения задач.
- Виртуальный диск ATA PIO, записываемая XVDISKFS, read-only initramfs XVRFS и слой VFS.
- Экспериментальные локальные аккаунты с salted PBKDF2-HMAC-SHA256-хэшами паролей и базовыми ограничениями домашнего каталога на уровне оболочки.
- Редактирование строки ввода, история команд, Tab-автодополнение и `SYSINFO` в стиле neofetch с логотипом X.
- Сеть через эмулируемую QEMU Intel E1000: DMA-кольца, ARP, IPv4, ICMP `PING`, DNS A-запросы, DHCP-клиент и UDP NTP-клиент.
- Экспериментальный синхронный TCP-клиент для обычного HTTP: ограниченные повторные передачи, до трёх редиректов, обработка `Content-Length` и chunked-ответов.
- `HTTPGET` показывает ограниченный HTTP-ответ; `FETCH` сохраняет полностью полученное небольшое тело ответа на записываемый диск.
- `NETSTAT` показывает счётчики кадров, ошибок, повторных TCP-передач и HTTP-запросов; `NETCHECK` проверяет базовую сеть.
- Команды времени `DATE`, `TIME`, `DATETIME`, `TIMEZONE` и `NTP`.

## Сборка и запуск

### Требования

- Windows 10/11, Linux или macOS.
- Rust через `rustup`, включая target `x86_64-unknown-none`.
- Python 3.10 или новее.
- QEMU (`qemu-system-x86_64`).
- C-компилятор и `xorriso` на Linux/macOS; сборочный скрипт может подготовить поддерживаемые вспомогательные инструменты на Windows.
- Доступ к интернету при первой сборке, если необходимые вспомогательные инструменты ещё не скачаны.

### Команды

Выполняй из корня репозитория:

```text
python setup.py
python -m unittest discover -s tests -v
python build.py --clean
python run.py
```

Сборка создаёт `build/xavieros.iso`. QEMU запускается с постоянным 16-МиБ диском `data/xavieros-disk.img`, эмулируемой Intel E1000 через user-mode NAT и виртуальными часами с базой UTC. **Не используй `python run.py --reset-disk`, если не хочешь удалить все файлы и аккаунты.**

## Команды консоли

Встроенная оболочка XavierOS не является POSIX shell и не запускает команды Linux.

| Команда | Описание |
|---|---|
| `HELP`, `ABOUT`, `VERSION`, `BANNER` | Справка, описание проекта, версия и логотип |
| `SYSINFO`, `INFO`, `CPU`, `MEM`, `PMM`, `HHDM`, `HEAP` | Информация о системе и памяти |
| `HEALTH`, `DIAG`, `SELFTEST`, `IDT`, `IRQ`, `UPTIME` | Диагностика и тесты ядра |
| `LS [PATH]`, `CAT PATH`, `STAT PATH`, `PWD`, `FSINFO`, `FSTEST` | Просмотр файлов и каталогов |
| `WRITE PATH TEXT`, `TOUCH PATH`, `MKDIR PATH`, `RM PATH`, `DF`, `FSCK`, `DISK` | Записанный диск и инструменты ФС (`FSCK` — проверка метаданных только для чтения; ремонт не выполняется) |
| `USERADD`, `LOGIN`, `LOGOUT`, `WHOAMI`, `USERS`, `PASSWD`, `HOME` | Экспериментальные локальные аккаунты |
| `NET`, `DHCP` | Состояние сети и настройка IPv4 |
| `PING HOST [COUNT]` | ICMP-проверка; от 1 до 8 запросов, по умолчанию 4 |
| `NETSTAT` | Сетевая конфигурация, счётчики кадров, повторных передач TCP и HTTP |
| `NETCHECK` | Проверка E1000, линка, ARP шлюза и DNS-запроса к `example.com` |
| `HTTPGET http://HOST/PATH` | Получить и показать ограниченный ответ обычного HTTP |
| `FETCH http://HOST/PATH /DISK/PATH` | Сохранить полностью загруженное небольшое HTTP-тело на диск |
| `DATE`, `TIME`, `DATETIME`, `TIMEZONE`, `NTP [SERVER]` | Дата, время, ручной UTC-offset и синхронизация NTP |
| `CALC A OP B`, `ECHO TEXT`, `CLEAR`, `REBOOT`, `HALT` | Калькулятор, вывод текста, очистка, перезагрузка и остановка |

### Примеры сетевых команд

```text
NET
NETCHECK
NETSTAT
PING 10.0.2.2 1
PING example.com 4
HTTPGET http://neverssl.com/
FETCH http://example.com/ /DISK/HOME/live/example.html
NTP time.cloudflare.com
DATETIME
TIMEZONE +0300
```

`FETCH` принимает один URL и один путь назначения, пишет только под `/DISK`, проверяет ограничения активного пользователя и сохраняет файл лишь после получения полного, неусечённого ответа со статусом 2xx. Размер буфера ограничен 16 КиБ. Не считай скачанное содержимое доверенным.

## Статус и ограничения

- XavierOS экспериментальна. Запускай её в QEMU или другой одноразовой виртуальной машине; поддержка обычного физического оборудования не проверена.
- Аккаунты не дают полной границы безопасности: команды работают в ring 0, а изоляция процессов в User Mode отсутствует. Не используй реальные или повторно используемые пароли.
- Сеть ориентирована на эмулируемую QEMU Intel E1000 и user-mode NAT. Физические сетевые карты, IPv6, HTTPS/TLS, режим прерываний E1000 и продление DHCP-аренды не реализованы.
- TCP пока представляет собой небольшой синхронный HTTP-клиент, а не полный TCP-стек. Повторные передачи ограничены установкой соединения и первым запросом; контроль перегрузки, универсальные потоки, постоянные соединения и восстановление после потери части ответа не реализованы.
- HTTP поддерживает до трёх редиректов, ограниченные буферы, `Content-Length` и `Transfer-Encoding: chunked`. HTTPS/TLS, gzip, произвольные HTTP-методы и неограниченные загрузки не поддерживаются. `FETCH` ограничен 16 КиБ и не сохраняет частичный ответ при ошибке.
- NTP и часовой пояс не сохраняются после перезагрузки. `TIMEZONE` позволяет задать фиксированное смещение UTC вручную; автоопределение местоположения и летнего времени не реализовано.
- XVDISKFS не журналируется и не защищена от аварийного завершения. `FSCK` проверяет метаданные, но не восстанавливает файлы. Делай резервные копии тестового диска.
- Планировщик кооперативный. Графическая оболочка, загрузчик пользовательских ELF-программ и изоляция виртуальных адресных пространств не реализованы.

## Структура проекта

```text
XavierOS/
├── .cargo/             # Конфигурация bare-metal target и linker
├── src/                # Ядро, память, хранилище, пользователи, часы и сеть
├── tests/              # Host-side проверки сборочных инструментов и регрессий
├── rootfs/             # Файлы для read-only initramfs XVRFS
├── Cargo.toml
├── build.py            # Сборка ядра и загрузочного ISO
├── run.py              # Запуск QEMU с диском и E1000 NAT
├── mkinitramfs.py      # Создание initramfs XVRFS
├── package_release.py  # Упаковка ISO и SHA-256
├── CHANGELOG.md
├── LICENSE
├── README.md
└── README.ru.md
```

Сгенерированные папки `target/`, `build/`, `tools/`, `dist/` и локальный образ диска не являются исходным кодом и не должны попадать в Git.
