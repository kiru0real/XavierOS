# XavierOS

**XavierOS — экспериментальная hobby-операционная система для x86_64, написанная на Rust.**

Ядро использует `no_std`, загружается через Limine и разрабатывается под Windows с запуском в QEMU.

- **Версия ядра:** `0.1.0`
- **Первый публичный предварительный релиз:** `v0.1.0-beta.1`
- **Лицензия исходников проекта:** MIT

[English README](README.md)

## О проекте

XavierOS — небольшой проект для изучения загрузки компьютера, работы ядра, видеовывода, клавиатуры и управления памятью. Ядро написано на Rust без стандартной библиотеки (`#![no_std]`) и ориентировано на `x86_64`.

Первая бета загружается сразу в собственную текстовую консоль. Это экспериментальная ОС для обучения и запуска в виртуальной машине, а не замена Windows или Linux.

## Возможности

- Bare-metal ядро Rust для `x86_64-unknown-none`.
- Загрузчик Limine и гибридный загрузочный ISO для BIOS/UEFI.
- Рисование текстовой консоли через framebuffer.
- Опрос PS/2-клавиатуры для ввода команд.
- Диагностический вывод через COM1 в окно PowerShell при запуске QEMU.
- Разбор memory map Limine и bitmap PMM для пригодных страниц ниже 4 ГиБ.
- HHDM: преобразование физических адресов в виртуальные и выделение обнулённых страниц.
- Самотесты PMM/HHDM.
- Команды для информации о системе, диагностики и целочисленный калькулятор.
- Сборка нативно в Windows без WSL и Linux.

## Сборка и запуск

### Требования

- Windows 10 или Windows 11.
- PowerShell 5.1 или новее.
- Rust и `rustup`.
- QEMU для Windows (`qemu-system-x86_64.exe`).
- Интернет при первой сборке: скрипт автоматически загружает бинарники Limine и Windows-сборку `xorriso`, если их ещё нет.

### 1. Установка Rust

В PowerShell:

```powershell
winget install --id Rustlang.Rustup -e
```

После установки закрой и заново открой PowerShell.

### 2. Установка QEMU

Скачай QEMU для Windows с [официальной страницы загрузок](https://www.qemu.org/download/#windows). Убедись, что `qemu-system-x86_64.exe` находится в `PATH` или в стандартной папке `Program Files`.

### 3. Сборка ISO

Открой PowerShell в корневой папке репозитория и выполни:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
.\setup.ps1
.\build.ps1
```

Настройка политики действует только для текущего процесса PowerShell и не меняет политику выполнения для всей системы.

После успешной сборки появится:

```text
build\xavieros.iso
```

### 4. Запуск в QEMU

```powershell
.\run.ps1
```

Нажми мышкой внутри окна QEMU, чтобы передать виртуальной машине клавиатурный ввод. Переключись на английскую раскладку и введи `HELP`, затем нажми Enter. Serial-журнал также виден в окне PowerShell.

Очистить результаты сборки и пересобрать проект:

```powershell
.\build.ps1 -Clean
```

## Команды консоли

Команды сейчас вводятся заглавными ASCII-символами. Это собственная небольшая оболочка XavierOS, а не POSIX shell; команды Linux не поддерживаются.

| Команда | Назначение |
|---|---|
| `HELP` или `?` | Список команд |
| `ABOUT` | Информация о проекте |
| `BANNER` | Логотип XavierOS |
| `SYSINFO` | Сводка о системе |
| `INFO` | Информация о ядре, архитектуре, загрузчике и интерфейсе |
| `VERSION` | Версия ОС (`0.1.0`) |
| `CPU` | Модель/производитель CPU через CPUID |
| `MEM` | Карта памяти и статистика PMM |
| `PMM` | Состояние физического аллокатора страниц |
| `HHDM` | Информация о прямом отображении |
| `DIAG` | Диагностика и тест памяти |
| `SELFTEST` | Повторный тест PMM/HHDM |
| `CALC A OP B` | Целочисленный калькулятор: `+`, `-`, `*`, `/`, с проверкой деления на ноль и переполнения |
| `ECHO TEXT` | Вывести текст |
| `CLEAR` | Очистить консоль |
| `REBOOT` | Запросить перезапуск виртуальной машины |
| `HALT` | Остановить CPU до перезапуска/закрытия QEMU |

Примеры:

```text
HELP
SYSINFO
MEM
CALC 12 * 4
CALC -7 + 3
ECHO HELLO XAVIEROS
SELFTEST
```

`SYSINFO` показывает модель CPU, которую QEMU представляет гостевой системе, и память, доступную XavierOS внутри виртуальной машины. Это не полная инвентаризация железа хост-компьютера и не общий объём установленной в нём RAM.

## Структура проекта

```text
XavierOS/
├── .cargo/config.toml  # Bare-metal target и параметры линковщика
├── src/main.rs         # Точка входа, framebuffer, клавиатура, shell
├── src/memory.rs       # Memory map Limine, HHDM и PMM
├── limine.conf         # Конфигурация загрузчика
├── linker.ld           # Размещение ELF и запросы Limine
├── setup.ps1           # Подготовка Rust target
├── build.ps1           # Сборка ядра и создание ISO
├── run.ps1             # Запуск ISO в QEMU
├── Cargo.toml
├── LICENSE
├── CHANGELOG.md
└── README.md
```

Не коммить генерируемые каталоги `target/`, `build/` и `tools/`. Для этого бинарного проекта рекомендуется хранить `Cargo.lock` в Git после его создания Cargo.

## Дорожная карта

Возможные следующие этапы:

- История команд, прокрутка и улучшенное редактирование ввода.
- Куча ядра и дополнительные тесты памяти.
- Обработка исключений и прерываний CPU.
- Драйвер клавиатуры на прерываниях.
- Менеджер виртуальной памяти и расширенный PMM.
- Хранилище, файловая система и позднее — небольшой userspace.

Это планы, а не обещанные функции текущей беты.

## Статус и ограничения

XavierOS — **экспериментальная hobby OS**, а не универсальная или безопасная операционная система. Сейчас отсутствуют рабочий стол, файловая система, сеть, userspace, планировщик процессов, куча ядра и полноценная подсистема прерываний/исключений. PMM управляет страницами только ниже 4 ГиБ и пока не поддерживает SMP. Клавиатура опрашивается напрямую и рассчитана на стандартные PS/2 Set 1 scancodes.

**Запускай XavierOS в QEMU или другой одноразовой виртуальной машине. Не используй её на основном компьютере и не доверяй ей защиту данных.** Для обычного использования на реальном оборудовании проект не проверялся.
