# XavierOS

**Экспериментальная хобби-операционная система x86_64 на Rust.**

Ядро `no_std` загружается через Limine; есть framebuffer-рабочий стол, консоль, файловое хранилище и экспериментальная сеть.

## О проекте

XavierOS — учебная хобби-ОС на Rust без стандартной библиотеки. Она загружается через Limine, рисует напрямую во framebuffer, обрабатывает ввод PS/2, управляет физической памятью и heap и содержит экспериментальные подсистемы диска и сети. В версии 0.2.2 добавлен графический Login Manager, первичная настройка администратора, вход с паролем, гостевая сессия LIVE-USER, блокировка/разблокировка и выход или переключение пользователя из системного меню.

## Возможности

- **Ядро и загрузка:** `x86_64-unknown-none`, Limine, IDT и обработчики исключений, PMM, HHDM, heap, PIC/PIT, PS/2-клавиатура и опрашиваемая PS/2-мышь.
- **Login Manager:** создание первой учётной записи администратора с подтверждением пароля, выбор аккаунта при запуске, вход с паролем, гостевая сессия `LIVE-USER` без пароля, блокировка/разблокировка, переключение пользователя и выход. Клавиатурные прерывания включаются до запуска экрана входа. Курсор мыши отображается и двигается через PS/2; выбор полей и управление экраном пока выполняются клавиатурой.
- **Рабочий стол:** полноэкранные обои с центральным кадрированием и билинейной интерполяцией, обновлённые Dock и иконки, альфа-смешиваемый курсор 24×24, окна приложений и восстановление сохранённого фона окна без полной перерисовки экрана при закрытии.
- **Files:** открывается в домашней папке активной сессии (`/DISK/HOME/<username>` или `/DISK/HOME/live`), поддерживает переходы по папкам, историю Back и избранную папку на время сессии, Up/Home/Disk/System, страницы списка, ограниченный текстовый предпросмотр, создание папки/пустого файла и удаление на записываемом `/DISK`. Встроенный корень доступен только для чтения; полноценного редактора пока нет.
- **Terminal:** существующая оболочка внутри окна; редактирование строки, история команд, Tab completion, учётные записи, файловые команды, сетевые диагностики и отчёты. Открытый Terminal захватывает клавиатурный фокус.
- **Network:** E1000 в QEMU, DHCP/static fallback, ARP/IPv4, ICMP `PING`, DNS/NTP, экспериментальные TCP/HTTP, проверки шлюза и DNS, счётчики пакетов.
- **Clock:** локальное время, фиксированное смещение от UTC, RTC и экспериментальная NTP-синхронизация.
- **Settings:** режимы 1024×768, 1280×720 и 1366×768 с запросом переключения через Bochs VBE, если адаптер поддерживает этот режим. Limine остаётся резервным способом выбрать разрешение при загрузке.
- **About:** вкладки обзора, ядра и лицензии.
- **Хранилище:** read-only XVRFS initramfs и записываемая XVDISKFS на QEMU ATA PIO диске.
- **Инструменты:** Python-скрипты сборки, создания initramfs, запуска и упаковки релиза; host-side тесты.

## Сборка и запуск

Требуются Rust через `rustup`, Python 3.10+, QEMU (`qemu-system-x86_64`) и инструменты сборки образа, описанные в скрипте (в том числе `xorriso`/Limine, если они нужны системе).

```powershell
python setup.py
python -m unittest discover -s tests -v
python build.py --clean
python run.py
```

ISO создаётся в `build/`. `run.py` подключает постоянный виртуальный диск `data/xavieros-disk.img`; сделай резервную копию перед экспериментами. Не используй `--reset-disk`, если не собираешься пересоздать диск.

## Управление рабочим столом

- Мышь: Dock и элементы приложений, если доступно PS/2 auxiliary-устройство.
- Клавиатура: `F` Files, `T` Terminal, `N` Network, `C` Clock, `S` Settings, `A` About, `X` системное меню. Стрелки перемещают выбор, Enter активирует, Escape закрывает окно или поднимается на уровень выше в Files. В Network клавиши `G` и `D` проверяют шлюз и DNS. В Clock клавиша `N` запускает NTP, `M`/`P` сдвигают часовой пояс на час, `S` сохраняет его.
- Files: нажми на папку для перехода; `BACK`/Backspace/`B` — история переходов, `UP`/Escape — родительский каталог; `PIN`/`P` закрепляет текущую папку, `FAVORITE`/`V` открывает её; `PREV`/`NEXT` переключают страницы; `NEW DIR` и `NEW FILE` создают элементы на `/DISK`; `DELETE` удаляет выбранный файл с `/DISK`. Вводи ASCII-имя и нажимай Enter; Escape отменяет создание.
- Terminal: команда `DESKTOP`, Escape или кнопка закрытия возвращает на рабочий стол.
- Системное меню: нажми `XAVIEROS` либо `X`; стрелками и Enter выбираются Desktop, Open Terminal, About, Lock Screen, Switch User, Log Out, Restart и Shut Down. Switch User и Log Out возвращают в Login Manager; Log Out сначала завершает текущую сессию и показывает сообщение о выходе. На экране входа используй `Up`/`Down` и Enter; пароль скрывается звёздочками. При первом запуске Tab или Enter переключают поля имени, пароля и подтверждения. В QEMU команда Shut Down отправляет запрос ACPI, после которого эмулятор может завершиться.
- Разрешение: выбери режим в Settings и нажми Apply Mode. Возможность переключения на лету зависит от VGA/Bochs VBE; альтернативные режимы доступны в Limine при загрузке.

## Команды оболочки

Введи `HELP` для полного списка. Основные группы: `SYSINFO`; `NET`, `NETSTAT`, `NETCHECK`, `PING`; экспериментальные `HTTPGET` и `FETCH`; `DATE`, `TIME`, `DATETIME`, `TIMEZONE`, `NTP`; `CONFIG`, `SETTINGS`, `REPORT`; `LS`, `CAT`, `STAT`, `WRITE`, `MKDIR`, `RM`, `DF`, `FSCK`; `USERADD`, `LOGIN`, `LOGOUT`, `WHOAMI`, `PASSWD`; диагностика `HEALTH`, `SELFTEST`, `TASKS`, `HEAP`, `MEM`.

## Статус и ограничения

XavierOS — экспериментальная ОС, не предназначенная для защиты важных данных. Рабочий стол и программы работают внутри ядра, а не в изолированных пользовательских процессах. GUI аккаунтов, проверка пароля и ограничения путей оболочки — прототип, а не граница безопасности от произвольного кода ядра. Files поддерживает навигацию, ограниченный текстовый предпросмотр и несколько действий над `/DISK`, но не является полноценным файловым менеджером/редактором. Сеть ориентирована на E1000 и user-mode NAT QEMU; HTTPS/TLS, IPv6 и полноценные сетевые приложения не реализованы. XVDISKFS не журналируется и не гарантирует восстановление после аварийного отключения. Смена разрешения на лету зависит от VGA/Bochs VBE. Перезапуск и выключение ориентированы на эмулятор; выключение в QEMU зависит от поддержки ACPI, физическое оборудование не проверялось. Гостевая `LIVE-USER` не имеет пароля и может обращаться к своей записываемой домашней папке только через проверки путей оболочки. Автоматическая проверка GitHub Releases пока не реализована, поскольку для безопасного запроса необходим HTTPS/TLS.

**Запускай XavierOS в QEMU или другой одноразовой виртуальной машине. Не используй её для защиты важных данных.**
