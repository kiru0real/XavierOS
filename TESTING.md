# XavierOS 0.1.1 Testing Checklist

This checklist is required before publishing `v0.1.1`. The CI workflow checks host tooling and compiles the kernel, but does not start QEMU.

## 1. Host-side checks

From the repository root:

```text
python -m compileall -q build.py run.py setup.py mkinitramfs.py package_release.py tests
python -m unittest discover -s tests -v
python mkinitramfs.py --output build/initramfs-check.xfs
```

If `rootfs/` has not changed, compare the generated image against the tracked one (`cmp initramfs.xfs build/initramfs-check.xfs` on macOS/Linux; use `fc /b initramfs.xfs build\initramfs-check.xfs` on Windows). If rootfs has changed, regenerate the tracked `initramfs.xfs` with `python mkinitramfs.py` and include that change.

## 2. Clean kernel/ISO build

```text
python setup.py
python build.py --clean
```

Expected result: exit code 0 and `build/xavieros.iso` exists. Save the full output if it fails.

## 3. Boot and shell smoke tests

Run `python run.py`. In the XavierOS console, run:

```text
HELP
VERSION
SYSINFO
IDT
IRQ
TIME
HEAP
FSINFO
FSTEST
DISK
LS /
LS /DISK
TASKTEST
SELFTEST
DIAG
```

Expected: no hang or reboot, no heap/VFS/kernel self-test failure, timer ticks increase, and the cooperative task counters complete.

## 4. Persistent storage regression

Only use the disposable 16 MiB image generated by `run.py`.

```text
MKDIR /DISK/REGRESSION
WRITE /DISK/REGRESSION/KEEP.TXT original contents
CAT /DISK/REGRESSION/KEEP.TXT
WRITE /DISK/REGRESSION/KEEP.TXT replacement contents
CAT /DISK/REGRESSION/KEEP.TXT
RM /DISK/REGRESSION/KEEP.TXT
RM /DISK/REGRESSION
```

Then write a new small file, close QEMU normally, start it again, and confirm `CAT` returns the same content. Do not use `FORMAT DISK` or `python run.py --reset-disk` unless intentionally discarding the test image.

This filesystem does not yet have journaling or crash recovery. Do not test it against a real drive or valuable disk image.

## 5. Exception path (run last)

Run `TRAP` only after other tests have passed. It intentionally executes an invalid opcode and stops QEMU while printing exception diagnostics.

## 6. Package release assets

After every relevant test passes:

```text
python package_release.py
```

This creates `dist/xavieros-0.1.1.iso` and `dist/SHA256SUMS.txt`. Verify the packaged ISO by booting that exact file, then attach both files to the GitHub Release draft.
